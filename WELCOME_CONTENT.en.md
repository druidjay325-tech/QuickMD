## What is QuickMD?

It is a **tool for capturing fleeting thoughts**.

Its entire mission is simple: **Have a thought. Write it down. Move on.**

No folder hierarchy, no complicated formatting panels, no cloud sync. Just press a shortcut and get what is in your head onto the page.

QuickMD believes in three things:

1. **Quick in, quick out** — With QuickMD running, press a shortcut and start writing.
2. **Local first** — Everyday note-taking works offline, and your notes stay on your own drive. Manually checking for updates requests release information from GitHub; it does not upload your notes.
3. **Your decisions stay yours** — No required tags, automatic categories, or sorting on your behalf. What you write is what it saves.

It is not here to replace your knowledge base. It is **the step before something enters your knowledge base**—when a thought is still in the air and you need a quick way to catch it.

## How to use it

**Keyboard shortcuts:**

| Shortcut | What it does |
|------|------|
| **Alt + Q** | Show the scratchpad and start writing. Press it again to hide it (you can change the shortcut in Settings). |
| **Esc** | Hide the scratchpad (in Preview, first return to Edit; when finding text or editing the title, first leave that operation). |

**Scratchpad toolbar:**

| Icon | Description |
|------|------|
| 📦 Archive | Move the current content to the library (save it in the main window’s note list, leaving the scratchpad ready for your next thought). |
| ↖ Open library | Open the main window. |
| 🗑 Clear | Ask for confirmation before clearing the scratchpad. Archive first if you want to keep the thought. |

**Main window toolbar and status bar (icons below are illustrative; refer to the button tooltips):**

| Icon | Description |
|------|------|
| **B** *I* S̶ | Bold, italic, strikethrough. |
| `< >` | Inline code. |
| H▾ | Heading level (H1–H6); the icon reflects the current line’s level. |
| ≡▾ | Bulleted list / numbered list / task list. |
| ⋯ → ▦ | More menu: insert a table. |
| ❝ | Blockquote. |
| ⋯ → — | More menu: horizontal rule. |
| 🔗 | Insert a link. |
| 🖼 | Insert a local image (copy it to `.assets` in the notes folder and reference it with a relative path). |
| ↗ | Show the scratchpad. |
| ⚙ (status bar) | Open Settings (shortcut, autosave, language, notes folder, appearance, and more). |
| ⋯ → ↶ ↷ | More menu: undo / redo. |

In Edit mode, you can also drop one or more images into the main window or scratchpad to insert them at the current cursor; Split view works too. Images are copied to the notes folder, leaving the originals untouched.

Right-click a note in the sidebar to rename, export, or delete it. Enter at least two characters in the search box to search filenames and note content in the library; archive a scratchpad thought first to find it here later. Tags, pinning, and changing the accent color are all close at hand.

By default, there is no need to look for a “Save” button. Autosave starts about one second after you stop typing, and the status bar shows how it is going. You can also press **Ctrl + S** to save manually; if you turn off autosave in Settings, remember to save your work yourself.

## Where are your notes?

Archived notes are plain `.md` files, stored here by default:

```
C:\Users\YourUsername\QuickMD\flashthoughts\
```

You can change the notes folder in Settings. The scratchpad draft is stored separately as `buffer.md` in the `QuickMD` data folder. Inserted images live in `.assets` inside the notes folder; remember to take that folder along when moving your notes.

Open them with any editor. You can leave QuickMD whenever you like. Your notes will always belong to you, not to an app.

The interface supports Chinese and English; switch between them in Settings. Changing the language does not translate, rename, or recreate existing default documents. The content you write is not automatically translated either.

Do not overthink it.

Open it and write something. A sentence, a link, a thought that came out of nowhere.

The value of a fleeting thought is not always clear now. It may become clear when you come back to it three months later.
